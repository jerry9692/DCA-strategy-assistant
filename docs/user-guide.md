# 定投策略助手 — 操作手册 v0.2

## 这是什么

一个本地 Web 工具，帮你决定每期定投该投多少钱。它不叫你"每次买一样多"，而是根据市场状态动态调整：市场跌得多就多买点，涨得高了就少买点。

只支持 **QQQ、VOO、SPY** 三只美股 ETF，不自动下单，不接券商。

---

## 启动

需要两个终端窗口。

**终端 1 — 启动后端**（需要 Python 3.10+）：

```bash
cd backend
pip install fastapi uvicorn pandas numpy yfinance sqlmodel
uvicorn app.main:app --reload
```

跑起来后访问 `http://127.0.0.1:8000`。首次使用会自动从 Yahoo Finance 拉历史数据并缓存到 `backend/data/` 下的 SQLite 文件。

**终端 2 — 启动前端**（需要 Node.js 18+）：

```bash
cd frontend
npm install
npm run dev
```

打开浏览器访问 `http://localhost:5173`。

## 界面说明

页面默认进入回测工作台。顶部可以切换亮色/暗色主题，也可以刷新当前回测。

**参数预设** — 顶部可以选择保守、均衡、激进或自定义。保守会降低加码上限并放宽触发条件，激进会提高上限并让信号更敏感。选择和手动参数会保存到浏览器 localStorage。

回测工作台分四个区域：

**顶部控制栏** — 选标的（QQQ/VOO/SPY）、基础金额（比如每期 100 美元）、定投频率（每周/每月）、回测起止日期。改任何参数都会自动触发回测。

**左侧策略列表** — 7 种定投策略，点击切换。每种策略下面有简短说明。

**中间主区域** — 从上到下依次是：
- 当前建议：本期该投多少钱、倍率、当前价
- 市场状态：用 50 日和 200 日均线判断当前是上升趋势、下降趋势还是震荡区间
- 决策理由：策略给出这个建议的原因
- 指标卡：总投入、期末价值、收益率、年化收益、最大回撤、相对固定/一次性买入、夏普比率、索提诺比率
- 基准区：固定 DCA 和一次性买入的完整指标
- 稳健参数建议：自动调优后展示推荐参数、多场景验证和候选排名
- 图表区：价格走势（绿点标记买入位置）、每期投入金额、组合市值、回撤、信号，以及策略对决

**右侧参数面板** — 调当前策略的参数，比如最低/最高倍率、均线窗口、RSI 阈值等。调参后图表和建议会自动刷新。

**稳健参数建议** — 右侧参数面板可以点击"自动调优"。系统不会寻找单段历史冠军，而是把当前区间、2020 熔断、2022 加息长熊、2023 修复和最近 12 个月放在一起验证，推荐一组跨场景更稳健的参数。默认只在最低 0.6-0.8 倍、最高 1.2-1.5 倍里搜索，让结果保持定投纪律。结果需要手动点击"应用"，不会自动覆盖当前参数。

**左侧策略对决** — 在策略列表底部勾选最多 3 个其他策略。系统会用同一个标的、金额、频率和时间范围跑同场对比，在主区域展示多条价值曲线和指标表。

**历史危机回放** — 回测工作台顶部提供 2020 熔断、2022 加息杀估值、2023 科技股修复等预设场景。点击后会自动切换回测日期，方便验证策略在极端行情里的表现。

**导出 CSV** — 当前建议卡右侧可以导出回测明细，包含动态策略、固定 DCA、一次性买入和策略对决的贡献记录。

## 七个策略怎么选

| 策略 | 一句话 | 适合谁 |
|---|---|---|
| **固定定投** | 每期一样多，不动脑 | 基准参考，用来和其他策略比效果 |
| **跌幅加码** | 跌得越狠买得越多 | 相信均值回归，不怕短期浮亏 |
| **均线偏离** | 低于均线多买，高于少买 | 喜欢看趋势的 |
| **历史分位** | 价格便宜时多买 | 看重估值区间的 |
| **RSI 情绪** | 超卖捡便宜，过热少买 | 相信短期情绪会反转 |
| **网格加权** | 在价格区间内分档调节 | 喜欢定量的、有计划的 |
| **组合评分** | 上面五个信号加权合成 | 不想单选，全都要 |

建议用法：先拿组合评分跑一次，看看各信号权重；再切到单个策略深入了解。

## 怎么看回测结果

核心看两个数：

- **收益率**：策略在整个回测区间内的总回报（期末价值 ÷ 总投入 - 1）
- **相对固定**：和傻瓜式固定定投比，多赚（或少赚）了多少。正数说明策略有效，负数说明还不如不动脑
- **相对一次性**：和期初一次性投入同样总预算相比，多赚或少赚多少
- **夏普/索提诺**：风险调整后的收益指标。夏普看整体波动，索提诺更关注下行波动

图表上绿点是策略实际买入的日子，柱状图的高低代表每期投入金额的变化——高低起伏越大说明策略对市场越敏感。

## 常见问题

**数据一直加载不出来？** 检查网络能否访问 Yahoo Finance。如果拉取失败，后端会尝试用本地缓存。缓存文件在 `backend/data/dca_assistant.sqlite`，删掉它会强制重拉。

**参数调了没反应？** 前端有 0.45 秒的防抖，改完等半秒就会自动刷新。

**想比较多个策略？** 在左侧"策略对决"里勾选 1-3 个策略，主区域会显示同场对比图和指标表。

**自动调优是不是能预测未来？** 不能。它只是用多个历史市场阶段做稳健验证，避免只拟合某一段行情。推荐参数代表"历史上跨场景更稳定"，不代表未来一定最优。

**回测区间怎么设？** 默认过去 5 年。想拉长到 10 年就改"开始"日期。注意数据太少（比如只选半年）时信号指标可能不准确（均线、分位需要足够窗口）。

**费率/滑点在哪设？** v0.2 暂未暴露到前端 UI，默认按 0 计算。后端其实支持，在 `backend/app/main.py` 的 backtest 路由里调 `DcaBacktester.run` 时传了 `fee_rate` 和 `slippage_rate` 参数，但目前从 `config.params` 取，前端 params 里没有这两个 key，所以始终为 0。后续版本会加到参数面板。
