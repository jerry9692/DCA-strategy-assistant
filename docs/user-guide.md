# 定投策略助手 — 操作手册 v0.5

## 这是什么

一个本地 Web 工具，帮你决定每期定投该投多少钱。它不叫你"每次买一样多"，而是根据市场状态动态调整：市场跌得多就多买点，涨得高了就少买点。

当前内置两类 ETF：美股 ETF 和 A 股基础指数 ETF。美股包括 QQQ、SPY、VOO、VTI、SCHD、BND、GLD、TQQQ 等核心/高波动标的；A 股第一版包括上证 50、沪深 300、中证 500、创业板、科创 50 五个基础指数 ETF。工具不自动下单，不接券商。

## 启动

Windows 下建议直接用启动脚本：

```powershell
.\start-dev.ps1
```

如果是第一次配置依赖，可以运行：

```powershell
.\start-dev.ps1 -Install
```

脚本会分别打开后端和前端窗口。也可以手工启动：

**终端 1 — 启动后端**（需要 Python 3.10+）：

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
```

跑起来后访问 `http://127.0.0.1:8000`。首次使用会自动从东方财富拉取历史数据（失败时回退到 Yahoo Finance）并缓存到 `backend/data/` 下的 SQLite 文件。

**终端 2 — 启动前端**（需要 Node.js 18+）：

```bash
cd frontend
npm install
npm run dev
```

打开浏览器访问 `http://localhost:5173`。

## 界面说明

页面默认进入回测工作台。顶部可以切换亮色/暗色主题、刷新当前回测，也可以进入设置页。

**参数预设** — 顶部可以选择保守、均衡、激进或自定义。默认最低倍率是 0.8，最高倍率是 1.2，定位是温和动态定投，不是大幅择时。选择和手动参数会保存到浏览器 localStorage。

**设置页** — 顶部齿轮按钮进入全局设置。这里可以配置 AI 解读、默认基础金额、默认定投频率、默认最低/最高倍率、无风险利率、交易费率和滑点率。默认倍率会用于未单独改过倍率的策略；如果你在某个策略的右侧参数面板里手动改了最低/最高倍率，那个策略会记住自己的倍率，之后切换回来仍使用单独设置。

回测工作台分四个区域：

**顶部控制栏** — 先选市场（美股 ETF / A股 ETF），再选标的；然后设置基础金额、定投频率（每周/双周/每月）、回测起止日期和快捷周期。改任何参数都会自动触发回测。A 股标的会用人民币符号展示金额，美股标的用美元符号展示。

**左侧策略列表** — 7 种定投策略，点击切换。每种策略下面有简短说明。

**中间主区域** — 从上到下依次是：
- 当前建议：本期该投多少钱、倍率、当前价
- AI 解读：用你的 OpenAI 兼容 API Key，自动用大白话解释"为什么本期建议投这个金额"
- 市场状态：用 50 日和 200 日均线判断当前是上升趋势、下降趋势还是震荡区间
- 决策理由：策略给出这个建议的原因
- 指标卡：总投入、期末价值、收益率、年化收益、持仓最大回撤、相对固定/一次性买入、夏普比率、索提诺比率
- 基准区：固定 DCA 和一次性买入的完整指标
- 稳健参数建议：自动调优后展示推荐参数、多场景验证和候选排名
- 图表区：滚动表现、价格走势（绿点标记买入位置）、每期投入金额、组合市值、账户回撤、信号，以及策略对决

**右侧参数面板** — 调当前策略的参数，比如最低/最高倍率、均线窗口、RSI 阈值等。调参后图表和建议会自动刷新。AI、费率、滑点和无风险利率属于全局设置，放在顶部齿轮按钮里的设置页。

**稳健参数建议** — 右侧参数面板可以点击"自动调优"。系统不会寻找单段历史冠军，而是把当前区间、2020 熔断、2022 加息长熊、2023 修复和最近 12 个月放在一起验证，推荐一组跨场景更稳健的参数。默认只在最低 0.6-0.8 倍、最高 1.2-1.5 倍里搜索，让结果保持定投纪律。结果需要手动点击"应用"，不会自动覆盖当前参数。

**左侧策略对决** — 在策略列表底部勾选最多 3 个其他策略。系统会用同一个标的、金额、频率和时间范围跑同场对比，在主区域展示多条价值曲线和指标表。

**历史场景** — 回测工作台顶部提供 2016 Brexit、2018 Q4、2020 熔断、2022 加息杀估值、2023 科技股修复等美股历史区间。点击后只是自动切换回测日期，方便观察策略在特殊历史阶段里的表现；它不是严格意义上的压力测试或未来情景模拟。当前 A 股标的暂不展示美股历史场景，后续会补 A 股专属场景库。

**导出 CSV** — 当前建议卡右侧可以导出回测明细。CSV 是按日期对齐的宽表：同一行展示本策略、固定 DCA、一次性买入和策略对决的投入金额、组合价值、倍率、评分、持仓回撤和账户回撤，打开 Excel 后不需要再手动透视。

**AI 解读** — 设置页里有 AI 解读设置。填入 OpenAI 兼容的 API Key（支持 OpenAI / DeepSeek / Moonshot / 智谱等），右侧栏会自动用白话解释"为什么本期建议投这个金额"。Key 只存在本地浏览器 localStorage，由后端转发请求，不落盘、不记录，也不会写入分享链接。默认勾选"建议变化后自动生成"，也可以取消后手动点击"生成解读"。

**选中文字解释** — 填好 API Key 后，在工作台里选中任意页面文字会出现"AI 解释"按钮。点击后，右侧 AI 区会切到"选中文字"，结合当前标的、策略建议和市场状态解释这段文字。输入框、日期框和 API Key 等表单内容不会触发这个按钮。

## 七个策略怎么选

| 策略 | 一句话 | 适合谁 |
|---|---|---|
| **固定定投** | 每期一样多，不动脑 | 基准参考，用来和其他策略比效果 |
| **跌幅加码** | 跌得越狠买得越多 | 相信均值回归，不怕短期浮亏 |
| **均线偏离** | 低于均线多买，高于少买 | 喜欢看趋势的 |
| **历史分位** | 价格便宜时多买 | 看重估值区间的 |
| **RSI 情绪** | 超卖捡便宜，过热少买 | 相信短期情绪会反转 |
| **网格加权** | 在价格区间内分档调节 | 喜欢定量的、有计划的 |
| **组合评分** | 上面五个信号加权合成 | 不想单选，全都要 |

建议用法：先拿组合评分跑一次，看看各信号权重；再切到单个策略深入了解。

## 怎么看回测结果

核心看两个数：

- **收益率**：策略在整个回测区间内的总回报（期末价值 ÷ 总投入 - 1）
- **相对固定**：和傻瓜式固定定投比，多赚（或少赚）了多少。正数说明策略有效，负数说明还不如不动脑
- **相对一次性**：和期初一次性投入同样总预算相比，多赚或少赚多少
- **夏普/索提诺**：风险调整后的收益指标。夏普看整体波动，索提诺更关注下行波动
- **持仓最大回撤**：指标卡里的回撤，表示已经买入资产本身经历过的最大回撤

图表上绿点是策略实际买入的日子，柱状图的高低代表每期投入金额的变化——高低起伏越大说明策略对市场越敏感。

滚动表现图用来回答"这策略是不是只在某几年好看"。长回测区间会显示滚动 3 年资金年化，较短区间显示滚动 1 年资金年化；每个点都假设从该滚动窗口起点才开始执行对应方案，只把窗口内新增投入和窗口末市值一起算 IRR。曲线越稳定，说明策略表现越不依赖单一阶段。

账户回撤图使用账户回撤口径：少投时未投入的预算视为现金，多投时会消耗现金预算。这样不同策略的风险暴露不会和固定 DCA 完全重合。

## 常见问题

**数据一直加载不出来？** 行情数据以东方财富为主数据源，Yahoo Finance 为备用。如果两个数据源都失败，后端会尝试用本地缓存（缓存末端距请求终点 7 天内仍返回）。检查网络能否访问 `push2his.eastmoney.com` 和 Yahoo Finance。缓存文件在 `backend/data/dca_assistant.sqlite`，删掉它会强制重拉。右上角的状态栏会显示当前数据来源（"东方财富" / "Yahoo Finance" / "东方财富缓存" / "Yahoo Finance 缓存" / "混合缓存"），便于排查。

**参数调了没反应？** 前端有 0.45 秒的防抖，改完等半秒就会自动刷新。

**想比较多个策略？** 在左侧"策略对决"里勾选 1-3 个策略，主区域会显示同场对比图和指标表。

**自动调优是不是能预测未来？** 不能。它只是用多个历史市场阶段做稳健验证，避免只拟合某一段行情。推荐参数代表"历史上跨场景更稳定"，不代表未来一定最优。

**回测区间怎么设？** 默认过去 5 年。想拉长到 10 年就改"开始"日期。注意数据太少（比如只选半年）时信号指标可能不准确（均线、分位需要足够窗口）。

**费率/滑点在哪设？** 在顶部齿轮按钮的设置页。默认 0%，可以按你的交易环境设置交易费率和滑点率。回测时会按比例扣减买入金额并抬高执行价，这些默认交易假设会应用到所有策略。

**回测里有股息吗？** 有，已经隐含。所有标的历史价格统一使用前复权：东方财富 `fqt=1`，yfinance `auto_adjust=True`，二者基准一致。返回的"close"已经是按分红和拆股调整过的价格，等价于"分红当天按收盘价再投资"。所以你看到的收益率、年化、回撤数字里都已经包含了分红再投资的复利效应，不需要再单独加。后续如果要支持"分红留作现金"模式，会作为可切换的开关。

**AI 解读怎么配置？** 在设置页的"AI 解读"里填入：
- API Base URL：服务商地址（OpenAI 用 `https://api.openai.com/v1`，DeepSeek 用 `https://api.deepseek.com`）
- 模型：常见选项如 `gpt-4o-mini`、`gpt-4o`、`deepseek-v4-pro`、`deepseek-v4-flash`，请按你所选服务商的最新文档填写
- API Key：你的 API 密钥（仅存浏览器 localStorage，每次请求由本地后端转发，不被记录）
- 勾上"建议变化后自动生成解读"，每次切策略或调参都会自动刷新

> **DeepSeek 用户注意**：旧版 `deepseek-chat` / `deepseek-reasoner` 模型名将于 2026-07-24 停用，届时将无法调用。推荐直接使用 `deepseek-v4-pro`（高能力）或 `deepseek-v4-flash`（低成本），二者均支持百万字上下文。

> **推理模型注意**：如果你接入的是推理模型（如小米 `mimo-v2.5`、DeepSeek-R1 等），模型会先消耗 token 做内部推理（`reasoning_tokens`），剩余 token 才输出正式回答。当 `max_tokens` 太小时，可能出现"HTTP 200 但 content 为空"的情况（推理用完了全部 token 预算）。本工具已把 explanation 的 `max_tokens` 提到 1500、chat 提到 2000 以兼容主流推理模型。如果仍然遇到空解读，请在设置页换用更大的模型或非推理模型。

解读只会用已经算好的指标来组织语言，不会自己编数字或预测未来。文案末尾自动追加免责声明。
