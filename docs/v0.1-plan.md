# 定投策略助手 v0.1 实施计划

## Summary

- 创建一个本地 Web 应用，第一版只支持 `QQQ`、`VOO`、`SPY`。
- 产品核心是“策略驱动的每期定投金额建议”，不是泛化行情工具或复杂交易系统。
- 技术栈固定为：`FastAPI + pandas/numpy + yfinance + SQLite/SQLModel + React/Vite/TypeScript + Apache ECharts`。
- 本文档记录 v0.1 的策略范围、技术选型、默认参数和验收标准。

## Implementation

- 项目结构：
  - `backend/`: FastAPI 服务、策略引擎、轻量回测、数据缓存。
  - `frontend/`: React/Vite 工作台 UI。
  - `docs/v0.1-plan.md`: v0.1 计划备忘。
- Backend：
  - 建立 `StrategyConfig`、`StrategyDecision`、`BacktestResult`、`ContributionEvent` 等模型。
  - 用 `yfinance` 拉取并缓存 QQQ/VOO/SPY 日线数据到 SQLite。
  - 自研 `DcaBacktester`，按定投频率逐期调用策略，计算建议金额、累计份额、组合价值和简版指标。
  - 提供 API：`GET /api/assets`、`GET /api/strategies`、`POST /api/recommendations/run`、`POST /api/backtests/run`。
- Strategy Core：
  - 内置 7 个策略：固定定投、跌幅加码、均线偏离、历史分位、RSI 情绪、网格加权定投、组合评分。
  - 所有策略都必须返回建议金额、倍率、评分、原始信号和 `reasons[]`。
  - 指标用 pandas/numpy 手写：SMA、rolling high/low、drawdown、RSI、rolling percentile、grid bucket。
- Frontend：
  - 主界面为策略工作台：顶部标的/基础金额/频率/区间，侧边策略选择，中部建议金额和图表，右侧参数面板。
  - 参数面板由后端策略 schema 驱动，使用 slider、number input、toggle、segmented control。
  - 图表用 Apache ECharts：价格与买入点、每期投入金额、策略价值曲线、回撤曲线、信号曲线。
  - 参数变更后 debounce 调用回测 API，保持调参即时反馈。

## Strategy Defaults

- 固定定投：`baseAmount = 100`。
- 通用倍率：`minMultiplier = 0.2`，`maxMultiplier = 2.5`。
- 跌幅加码：默认观察 `252` 个交易日高点。
- 均线偏离：默认 `200` 日均线。
- 历史分位：默认 `756` 日窗口。
- RSI：默认 `14` 日，超卖 `30`，过热 `70`。
- 网格加权：默认滚动 `252` 日高低点，`8` 档，只调节买入金额，不卖出。
- 组合评分：默认等权整合回撤、均线、分位、RSI、网格信号。

## Test Plan

- Backend 单测：
  - 每个策略用固定价格序列验证金额倍率、边界值和 reasons。
  - 回测验证非交易日顺延、手续费/滑点、累计份额、最大回撤。
  - 组合评分验证权重变化影响结果，金额始终在上下限内。
- Frontend 验收：
  - 切换 QQQ/VOO/SPY、切换策略、调参数后，建议金额、理由和图表同步刷新。
  - 桌面与移动宽度下文字不重叠，参数控件可操作。
- 手工验收：
  - 分别用 QQQ、VOO、SPY 跑 5 年和 10 年区间。
  - 固定定投与动态策略可并排比较。
  - 数据失败时显示错误或缓存状态，不生成伪建议。

## Assumptions

- v0.1 只做辅助决策，不自动下单，不接券商 API。
- v0.1 只支持美元、日线、QQQ/VOO/SPY。
- 网格策略是“网格加权定投”，不是完整买卖网格。
- 后续若要大规模参数优化再考虑引入 `vectorbt`；若要真实买卖网格再考虑 Backtrader 类框架。
