# 变更说明 — 2026-05-23 P2 C1-US 美股 ETF 扩展

承接 `roadmap-2026-q3.md` 的 C1，本次先做美国市场 ETF 扩展，不引入 A 股数据源或跨市场日历。目标是覆盖适合定投分析的主流指数基金，并把高波动/杠杆标的和普通长期资产区分展示。

## 新增标的

核心/长期定投分析：

- 核心宽基：`QQQ`、`SPY`、`VOO`、`VTI`、`DIA`、`IWM`
- 红利价值：`SCHD`、`VYM`、`VTV`、`VUG`
- 国际股票：`VXUS`、`VEA`、`VWO`
- 债券防守：`BND`、`AGG`、`TLT`、`IEF`
- 商品替代：`GLD`

高级/高波动：

- 行业集中：`XLK`、`SOXX`、`SMH`
- 杠杆 ETF：`TQQQ`、`QLD`、`UPRO`、`SSO`
- 比特币现货 ETF：`IBIT`

暂不加入反向 ETF（如 `SQQQ`、`SPXU`），因为长期定投语义弱，容易误导。

## 实现

- `SUPPORTED_ASSETS` 从简单 `symbol -> name` 扩展为资产元数据：
  - `name`
  - `market`
  - `currency`
  - `category`
  - `categoryLabel`
  - `riskLevel`
  - `riskNote`
- `Asset` API model 新增上述展示字段。
- `/api/assets` 返回完整资产元数据；旧测试中 monkeypatch 成 `{"VTI": "..."}` 的形态仍兼容。
- `get_available_range` 为新增 ETF 补充 Yahoo Finance 最早可用日期。
- 前端标的选择器按 `categoryLabel` 使用 `<optgroup>` 分组。
- 选中 `riskLevel="advanced"` 的标的时，在工作台顶部显示风险提示条。
- `ASSET_MARKETS` 扩展到所有新增美股 ETF，为后续 A 股市场适配保留结构。
