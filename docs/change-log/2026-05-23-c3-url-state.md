# 变更说明 — 2026-05-23 P2 C3 URL state 同步

承接 `roadmap-2026-q3.md` 的 C3，本次完成回测配置的 URL 同步，让用户可以直接复制地址分享当前工作台状态。

## 实现

- 页面初始化时先读 URL query；只要 URL 里存在任一分享字段，就以 URL 为准，不混入本机 localStorage，避免分享链接被接收者的本地偏好污染。
- 页面状态变化后用 `history.replaceState` 写回地址栏，不产生一长串浏览器历史记录。
- URL 只写必要字段和非默认字段：日期区间始终保留；默认标的、默认策略、默认金额、默认倍率、0 费率/滑点、4% 无风险利率、默认策略参数都会省略，让分享链接保持可读。
- 同步字段：
  - `symbol`
  - `strategy`
  - `start` / `end`
  - `amount`
  - `frequency`
  - `min` / `max`
  - `preset`
  - `scenario`
  - `compare`
  - `riskFree`
  - `fee` / `slippage`
  - 策略参数：`p.<paramKey>=<value>`
- localStorage 仍保留，用于无 URL 参数时恢复上次使用状态。

## 测试

新增 3 条前端单元测试：

- 无分享字段时 `readUrlSettings` 返回 `null`
- URL 能解析基础字段、对比策略和 `p.xxx` 策略参数
- `buildShareableSearch` 输出稳定 query string

验证：

