# 变更说明 — 2026-05-24 P3 D1 滚动窗口表现

承接 `roadmap-2026-q3.md` 的 D1，本次新增“滚动窗口表现”图，用来回答单一总收益率回答不了的问题：策略是否只在少数年份表现好，还是在不同市场阶段都有相对稳定的资金年化表现。

## 实现

- `BacktestResult` 新增 `rollingPerformance` 字段。
- 后端根据回测区间长度自动选择窗口：
  - 回测区间约 5 年以上：滚动 3 年表现。
  - 回测区间约 2-5 年：滚动 1 年表现。
  - 回测区间短于约 2 年：不展示滚动图，前端显示提示。
- 前端新增“滚动 N 年表现”图，同时展示：
  - 本策略
  - 固定 DCA
  - 一次性买入
- OpenAPI schema 和前端生成类型已同步。
- README、user-guide、roadmap、task-list 已更新。

## 口径修正

初版用的是现金流调整后的时间加权收益。这个口径适合看“标的价格本身在窗口内涨跌了多少”，但不适合做 DCA 策略对比。

原因是：本项目里的策略都只买不卖，且标的是同一个 ETF。时间加权收益会刻意剔除买入金额和买入时点差异，所以本策略、固定 DCA、一次性买入会退化成同一条价格收益曲线，用户看到三条线长期重合。

修正后，滚动表现改为“窗口内新增投入 IRR”：

- 每个点都假设从该滚动窗口起点才开始执行对应方案。
- 本策略和固定 DCA：只统计窗口内实际新增买入形成的份额，窗口末按当日价格估值。
- 一次性买入：把同一窗口内固定 DCA 的总预算视为窗口起点一次性投入，窗口末按当日价格估值。
- 这样三条线会反映真实的投入时点差异，不会因为口径选择而天然重合。

## 备注

滚动表现图不是预测未来，也不是重新调参；它只是把同一套策略放到多个连续历史窗口里观察。它比汇总收益更适合发现“某策略是否只靠某一段行情撑起总结果”。
